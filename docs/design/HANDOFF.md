# Совместные расходы: передача дизайна в разработку

Этот файл для разработчика (и для Claude Code). Здесь всё, что нужно, чтобы сверстать фронт на React по макетам.

- `screens/*.html` — 24 экрана, обычный HTML. Открываются в браузере, `index.html` — оглавление. Отсюда брать отступы, размеры и тексты один в один.
- `copy.ru.json` — все тексты интерфейса, шуточные в отдельном разделе `fun`.
- `source/` — исходники холста (`.dc.html` + `canvas.json`). Нужны, только чтобы вернуть правки обратно на холст.
- `screens/Main.html` — концепция и записка с решениями. Прочитать первым.

Порядок работы: группа (`M02`, `D02`), потом добавление расхода (`M04`–`M06`), потом погашения (`M07`, `M08`, `S01`). Остальное после.

### Типографика

- Шрифт: **Golos Text** 400/500/600/700, Google Fonts. Запасной: `system-ui, sans-serif`.
- Все суммы: `font-variant-numeric: tabular-nums; white-space: nowrap` (класс `.n` в макетах).
- Основной текст 16px, line-height 1.5. Подписи 13–15px. Заголовок экрана 28px/700 на телефоне, 30–36px на компьютере.
- Баланс-герой: 44px/700, letter-spacing −0.02em (телефон), 40px на компьютере.
- Письма: системные шрифты (`-apple-system, Segoe UI, Roboto, Helvetica, Arial`), табличная вёрстка.

### Размеры

- Радиусы: 8 (мелкие кнопки), 10 (поля, кнопки), 12 (карточки), 14 (главная кнопка), 16–20 (шит, модалка), 999 (плашки-пилюли).
- Высоты: главная кнопка 56, обычная 44–48, чипы 36. Цели касания не меньше 44.
- Отступы по бокам на телефоне 20, на компьютере контейнер `max-width: 1120px`, поля 24.
- Теней нет, кроме переключателя сегментов (`0 1px 2px rgba(20,24,32,.12)`) и тоста.

## 4. Денежные правила (обязательны в коде)

1. **Только целые копейки.** Хранить и считать в минорных единицах (integer). Никаких float.
2. **Поровну:** `base = floor(total / n)`, остаток `r = total − base·n` копеек раздаётся по 1 коп. первым `r` участникам **в порядке вступления в группу**. Пример: 1 000,00 на троих → 333,34 · 333,33 · 333,33.
3. **Долями:** доля участника `floor(total · w_i / Σw)`, остаток копеек — тем же правилом по порядку вступления. Пример: 2 000,00 при 1:1:1:2 → 400 · 400 · 400 · 800.
4. **Точными суммами:** сохранение запрещено, пока `Σ долей ≠ total`. Показывать разницу и быстрое действие «Добавить разницу последнему изменённому».
5. **Баланс** = заплатил − Σ своих долей + подтверждённые отправленные погашения − подтверждённые полученные. `Σ балансов группы = 0` всегда. Нарушение — баг, логировать.
6. **Ожидающие и отклонённые погашения в баланс не входят.** Ожидающие показываются рядом.
7. **Минимальные переводы:** жадно сводим максимального должника с максимальным кредитором, пока все не обнулятся. Пример из брифа: 3 перевода.
8. **Одна валюта на группу.** Общий итог — отдельно по каждой валюте, без сложения.
9. **Правка старого расхода** пересчитывает всё, включая уже подтверждённые погашения. Баланс может развернуться.

### Контрольный пример (Поездка в Казань)

После 4 расходов: Аня +7 400,00 · Борис −4 233,34 · Вика −33,33 · Гена −3 133,33.
После погашения Бориса и правки такси до 1 200 (ожидающее погашение Гены 2 000 не учтено):
Аня +3 166,66 · Борис +133,34 · Вика −100,00 · Гена −3 200,00.
Переводы: Гена → Аня 3 166,66 · Гена → Борис 33,34 · Вика → Борис 100,00.
Хорошо подходит как фикстура для юнит-тестов.

## 5. Поведение

- **Живые обновления.** Изменения других участников применяются без перезагрузки. Изменённые числа получают подсветку `changed` и зачёркнутое старое значение, пока экран не просмотрен. Тост, без звука и анимации-отскока.
- **Форма открыта.** Данные под формой не перерисовываем. Показываем `FormNotice`, балансы обновляются после сохранения.
- **Конфликт.** У расхода `version`. Сохранение с устаревшей версией возвращает 409. Клиент показывает `ConflictSheet` с обеими версиями.
- **Нет связи.** Баннер со временем последних данных, суммы приглушены, добавление недоступно, черновик формы хранится локально.
- **Закрытая группа.** Кнопки добавления и правки не рендерятся совсем. Баннер «Только просмотр». У создателя есть «Открыть снова».
- **Тон.** Нейтральные слова: «С тебя», «Тебе вернут», «Ты в расчёте». Слова «долг» в интерфейсе нет. Мемы только в местах из `copy.ru.json → fun`, никогда на экране «С тебя» и в сообщениях об отказе.
